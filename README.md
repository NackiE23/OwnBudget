# OwnBudget

Місячний бюджет замість Excel: вписуєш Salary за місяць, і система розподіляє його за відсотками між категоріями, рахує нерозподілений залишок і «Знято з накопичень» від «Загальні Накопичення» попереднього місяця.

Стек: Django 5.2, Django REST Framework, SQLite, адмінка на [Unfold](https://unfoldadmin.com/). Вимоги описано в [ТЗ: Budget (Django)](https://claude.ai/artifact/1bfjR9bwWo89zyySAzBpA4).

## Запуск локально

```bash
uv sync
cp .env.example .env          # для локальної роботи достатньо DJANGO_DEBUG=1
uv run python manage.py migrate
uv run python manage.py createsuperuser
uv run python manage.py runserver
```

Адмінка відкривається за адресою `http://127.0.0.1:8000/<DJANGO_ADMIN_URL>`, за замовчуванням `/admin/`. Кореневої сторінки немає навмисно.

Імпорт історії з Excel (спершу пробний запуск, він нічого не зберігає):

```bash
uv run python manage.py import_excel "Загальні витрати.xlsx" --dry-run
uv run python manage.py import_excel "Загальні витрати.xlsx"
```

Тести:

```bash
uv run python manage.py test
```

### Правила розрахунку

- Ліміт категорії дорівнює Salary × відсоток. Якщо відсотка немає, ліміт вводиться сумою.
- Нерозподілено = Salary − сума лімітів усіх категорій, крім «Знято з накопичень».
- Якщо всі ліміти задані відсотками, а їхня сума не 100%, адмінка показує попередження.
- «Знято з накопичень» дорівнює відсотку (20% за замовчуванням) від «Загальні Накопичення» попереднього місяця. База — фактична сума («Як Є»), а якщо її ще не внесли, то ліміт. Для першого місяця історії сума лишається ручною.
- Після збереження місяця перераховується й наступний, бо його «Знято» залежить від цього.
- Закритий місяць заморожений: його не перераховують і не редагують, доки його не відкрити знову. Нотатки й позначку змінювати можна.
- Новий місяць копіює з попереднього Salary, відсотки (або фіксовані суми) і типи рядків. Суми рядків не копіюються.

### Імпорт з Excel

- Стовпці шукаються за назвами: лівий блок у рядку з «Month», категорії рядком вище. Кожна категорія займає два стовпці, «Як Є» → `actual` і «Ціль/Межа» → `limit_amount`.
- Значення беруться з кешу формул. Формула `=G13*30%` дає відсоток 30, частка `0.3` теж. Число без формули стає ручним лімітом.
- Колір комірки «Як Є» стає позначкою категорії: жовтий → золотий, зелений, червоний.
- Food записується в «Як Є» категорії «Їжа», якщо там порожньо. Якщо обидва значення є й вони різні, береться «Як Є», а звіт це показує.
- Savings розбирається порядково: `$` → USD, `€` → EUR, `zl` → PLN, без символу UAH, решта тексту стає призначенням (нові призначення створюються). `2000+4000 облігації` дає один запис на суму, `8000 + $200` два. Рядки з дужками чи `|` стають записами без суми з оригіналом у `raw_text`.
- Additional incomes стає одним рядком доходу: сума гривневих доданків, весь текст у примітці. Суми в інших валютах у суму не входять, звіт їх перелічує.
- Ключ запису — місяць. Повторний запуск оновлює відкриті місяці без дублів, закриті пропускає (`--overwrite-closed`, щоб перезаписати). Після імпорту закриваються всі місяці, крім останнього у файлі.
- Після імпорту ліміти перераховуються за правилами застосунку. Якщо результат розходиться з таблицею, звіт це показує.

### API

| Метод і шлях | Що робить |
| --- | --- |
| `GET/POST /api/budget/months/` | Місяці з розрахованими полями й вкладеними даними; фільтр `?year=2025` |
| `POST /api/budget/months/next/` | Створити наступний місяць |
| `POST /api/budget/months/{id}/close/`, `/reopen/` | Закрити або відкрити місяць |
| `/api/budget/allocations/`, `/lines/`, `/savings-entries/` | Дані місяця, фільтр `?month=<id>` |
| `/api/budget/categories/`, `/line-types/`, `/destinations/` | Довідники |

## Рішення щодо відкритих питань ТЗ

| Питання | Рішення |
| --- | --- |
| Total expenses вручну чи з рядків | Зберігається як введено. Поруч показуються сума рядків витрат і розбіжність. Порожнє поле означає суму рядків |
| 01.26: різні значення в P і H | Імпорт бере «Як Є» (P) і показує розбіжність із Food (H) у звіті. Остаточне значення обираєш ти |
| Crypto | Запис накопичень із призначенням «Crypto». У таблиці це гривні («2000 на USDT»), тож валюта UAH, а «на USDT» лишається приміткою |
| Кольори статусу | Необов'язкове поле «позначка» (золотий, зелений, червоний) і в місяця, і в кожної категорії, без логіки. Імпорт бере колір категорії з Excel |
| Notes «-сума …» | Лишаються текстом. Розбір буде в ТЗ історії значних витрат |
| Складні рядки Savings | Імпортуються як запис без суми, оригінал лежить у `raw_text`. Дані не губляться, звіт їх перелічує |
| PLN і USDT | Зберігаються без конвертації, як USD і EUR |
| Salary набрано формулою | Зберігаються і результат (`salary`), і вираз (`salary_expression`) |
